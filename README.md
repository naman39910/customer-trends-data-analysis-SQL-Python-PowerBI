## 📌 Project Overview

This project analyzes customer shopping behavior to understand **purchasing patterns, customer segments, product performance, discounts, subscriptions, shipping preferences, and revenue contribution**.

### End-to-End Workflow

**Raw CSV Data → Python Data Cleaning & Transformation → SQL Analysis → Power BI Dashboard → Business Insights**

The project demonstrates how Python, SQL, PostgreSQL, and Power BI can be combined to solve practical business analytics problems.

---

## 🎯 Business Objective

The main objectives of this project are to:

- Understand customer purchasing behavior
- Compare revenue and spending across customer groups
- Identify high-performing products and categories
- Evaluate discounts and subscription behavior
- Segment customers based on purchase history
- Analyze shipping and purchasing-frequency patterns
- Build an interactive dashboard for business reporting

## 📊 Dataset

The project uses the **Customer Shopping Behavior** dataset containing **3,900 customer records and 18 original columns**.

### Dataset Columns

| Column | Description |

| Color | Product color |
| Season | Season of purchase |
| Review Rating | Customer product rating |
| Subscription Status | Subscription indicator |
| Shipping Type | Shipping method |
| Discount Applied | Whether a discount was applied |
| Promo Code Used | Whether a promo code was used |

| Frequency of Purchases | Purchase frequency |

The Python analysis also checks missing values, including missing values in **Review Rating**.

## 🔄 Project Workflow

### 1. Data Loading

The CSV dataset is imported into Python using Pandas.

### 2. Data Exploration

The notebook performs:

- Dataset dimension checks
- Data type checks
- Missing-value analysis
- Descriptive statistics
- Unique-value exploration

### 3. Data Cleaning & Transformation

The analysis includes:

- Standardizing column names
- Checking data quality
- Validating discount and promo-code fields
- Removing the redundant `promo_code_used` field after validation
- Creating an `age_group` feature using quartile-based segmentation
- Converting purchase-frequency categories into approximate day intervals

### 4. Database Integration

The transformed DataFrame is loaded into a database table named:

    customer

The notebook includes database connectivity examples for:

- PostgreSQL
- MySQL
- Microsoft SQL Server

### 5. SQL Analysis

SQL queries are used to answer 10 practical business questions related to revenue, products, discounts, subscriptions, loyalty, and customer demographics.

### 6. Power BI Dashboard

The processed data is used to build an interactive dashboard for visual business analysis.

---

## 🔎 Business Questions Answered

The project answers the following questions:

1. What is the total revenue generated by male vs. female customers?
2. Which customers used a discount but still spent more than the average purchase amount?
3. Which are the top 5 products with the highest average review rating?
4. How does average purchase amount compare between Standard and Express Shipping?
5. Do subscribed customers spend more than non-subscribers?
6. Which 5 products have the highest percentage of discounted purchases?
7. How can customers be segmented into New, Returning, and Loyal customers based on previous purchases?
8. What are the top 3 most purchased products within each category?
9. Are repeat buyers with more than 5 previous purchases more likely to subscribe?
10. What is the revenue contribution of each age group?

## 🚀 How to Run the Project

### Prerequisites

Install the following:

- Python 3.9+
- Jupyter Notebook or JupyterLab
- PostgreSQL
- Power BI Desktop

### Install Python Libraries

    pip install pandas sqlalchemy psycopg2-binary pymysql pyodbc

### Clone the Repository

    git clone https://github.com/naman39910/customer-trends-data-analysis-SQL-Python-PowerBI.git

Navigate to the project directory:

    cd customer-trends-data-analysis-SQL-Python-PowerBI

### Run the Python Notebook

Open:

    Customer_Shopping_Behavior_Analysis.ipynb

Make sure the CSV file is available in the same working directory and run the notebook cells sequentially.
